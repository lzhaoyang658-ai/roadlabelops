# RoadLabelOps 道路目标标注规范

版本：1.0.0
适用范围：V1 单目 2D 道路视频矩形框标注与抽样验收

## 1. 标签定义

| 标签 | 纳入对象 | 排除或易混淆对象 |
| --- | --- | --- |
| `car` | 轿车、SUV、MPV、出租车 | 皮卡和明确承担货运功能的车辆归入 `truck` |
| `bus` | 公交车、客车、中大型载客巴士 | 普通面包车归入 `car` |
| `truck` | 卡车、货车、牵引车、皮卡 | 普通 SUV 不归入 `truck` |
| `motorcycle` | 摩托车、电动摩托及其可见骑手整体以车辆框为主 | 自行车归入 `bicycle`；骑手本人不重复标为 `pedestrian` |
| `bicycle` | 自行车及可见骑行主体 | 摩托车、电动摩托归入 `motorcycle` |
| `pedestrian` | 道路、路肩或人行区域中可辨识的行人 | 车内人员、海报、倒影不标注 |
| `traffic_light` | 可辨识、面向道路参与者的交通信号灯 | 车辆尾灯、装饰灯不标注 |
| `traffic_sign` | 可辨识的道路标志牌 | 广告牌、店招不标注 |

当前 YOLO 预标注契约覆盖上述八类；低置信度、遮挡或漏检目标仍需在 CVAT 中人工补充和修订。

## 2. 矩形框规则

- 一个真实对象对应一个框，不得重复框选。
- 框应贴合对象当前可见外轮廓；允许每边约 2～5 像素操作余量。
- 遮挡对象只框可见部分，不凭空推测被遮挡范围。
- 截断到画面边缘的对象，只要仍能确认类别且可见部分不少于约 25%，就应标注。
- 在 1280×720 画面中，宽或高不足 20 像素且无法可靠辨类的远处目标可忽略。
- 同一对象不能同时使用互斥类别；类别不确定时进入人工复核，不用高置信度猜测。

## 3. 抽样验收判定

单个预测框满足以下条件时记为“通过框”：

1. 类别符合标签定义；
2. 框覆盖目标主要可见区域，且没有明显包含大面积无关背景；
3. 不是重复框，也不是对倒影、海报或车内人员的误检。

抽检帧中的明显目标符合标注门槛、但没有任何匹配框时，记为“漏标”。无法仅凭静态画面确定的情况记为“疑似”，不强行计入错误。

V1 技术验收建议门槛：

- 抽样框精确率 ≥ 90%；
- 抽样目标召回率 ≥ 85%；
- 无明显错误或漏标的帧占比 ≥ 80%；
- 不存在持续性的类别映射错误或重复框问题。

其中：

- 抽样框精确率 = 通过框数 ÷ 预测框总数；
- 抽样目标召回率 = 通过框数 ÷（通过框数 + 明显漏标数）；
- 无错误帧率 = 无明显错框且无明显漏标的抽检帧数 ÷ 抽检总帧数。

这些指标是人工视觉抽样结果，不等同于完整数据集 mAP，也不能替代双人复核或正式 Ground Truth 评测。
